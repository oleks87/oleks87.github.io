# Lampa для Media Station X

Свой минимальный стартовый портал для MSX на телевизоре: одно меню, один пункт, ссылка на lampa.mx. Ничего личного в файлах нет.

В MSX: Settings -> Start Parameter -> Setup -> `oleks87.github.io`

Файлы: `msx/start.json` (какое меню открыть), `msx/menu.json` (само меню).
Добавить пункт: новый блок в `items` в `msx/menu.json`, затем commit и push.
